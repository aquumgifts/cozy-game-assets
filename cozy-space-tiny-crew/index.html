What's inside

12 tiny pixel art characters for top-down RPGs and adventure games, sized for a 16 px tile grid (they match Cozy Space Interiors).

Characters: captain, pilot, engineer, doctor, officer, mechanic, cadet, scientist, cook, guard, robot, alien

sheets/   one PNG per character, 3 columns x 4 rows of 16 x 16 frames:
            row 1  walk down     row 2  walk left
            row 3  walk right    row 4  walk up
            columns: step, stand, step
          Play the columns as 1-2-3-2 at about 8 fps for a walk cycle;
          the middle column is the idle pose. This is the common RPG sheet
          layout (RPG Maker style, but 16 px), so most engines and
          tutorials work as-is.
examples/ all-tiny-crew.png, every character on one sheet

Everything comes in 1x, 2x and 4x (nearest-neighbor). Transparent PNG, 1 px outline, light from the left.

Part of the Cozy Space set (aquumgifts.itch.io): Interiors, Station, Walking Crew, Portraits, Pixel Font and more in the same palette. See LICENSE.txt for what you can do with them.

Use it in Godot 4

Set Project Settings → Rendering → Textures → Default Texture Filter to Nearest for crisp pixels. Each sheet is a grid of 3 × 4 frames (see the layout above), so a Sprite2D can step through it:

$Sprite2D.texture = load("res://cozy-space-tiny-crew/examples/1x/all-tiny-crew.png")
$Sprite2D.hframes = 3
$Sprite2D.vframes = 4
$Sprite2D.frame = 0  # row r, column c: r * 3 + c
