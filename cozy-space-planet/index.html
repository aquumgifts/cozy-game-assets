What's inside

Ground tiles and 18 props to build the outside of a space base: dusty ground, grey regolith, alien moss, ice, metal plate paths, a habitat dome, landing pad, rover, solar panel, crystals, alien plants and more. Same 3/4 top-down view and palette as Cozy Space Interiors, Furniture and Tiny Crew.

tiles/     14 ground tiles, 16 x 16, seamless (dust, regolith, moss and ice in
           3 variants each, plus 2 metal plates). Mix the variants so the
           ground does not look repeated.
tileset/   the same tiles on one sheet (7 columns, 16 px grid)
props/     one PNG per prop, sized in whole tiles and sitting on the bottom edge:
  rock           16 x 16 px
  bigrock        32 x 16 px
  crystal        16 x 16 px
  crystalpurple  16 x 16 px

  antenna        16 x 16 px

  solarpanel     32 x 16 px

  rover          32 x 16 px
  tent           32 x 16 px
  campfire       16 x 16 px
  barrels        32 x 16 px
sheet/     every prop packed on a 256 px wide sheet
examples/  a base on the planet surface built from this pack and Tiny Crew

Everything comes in 1x, 2x and 4x (nearest-neighbor). Transparent PNG props with a 1 px outline, light from the top left.

Use it in Godot 4

Set Project Settings → Rendering → Textures → Default Texture Filter to Nearest for crisp pixels. Drop the PNGs into your project and use them as textures; for tiles, add the sheet to a TileSet with the tile size from the README.

$Sprite2D.texture = load("res://cozy-space-planet/examples/example-surface-1x.png")
