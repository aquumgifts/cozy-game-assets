  crew-navy, crew-teal, crew-gray, crew-slate, crew-plum,

SHEET LAYOUT

Every character is one PNG sheet: 4 columns x 5 rows of equal frames.

  row 1  walk down (facing the camera)   4 frames
  row 2  walk up (seen from behind)      4 frames
  row 3  idle, with a blink on frame 3   4 frames
  row 4  walk left (side view)           4 frames
  row 5  walk right (side view)          4 frames
Frame sizes:
  sheets/1x   24 x 40 px
  sheets/2x   48 x 80 px
  sheets/4x   96 x 160 px

The feet sit at the same point in every frame (x = 50%, y = 60% of the frame), so frames line up without offsets. Suggested speed: 8 frames per second for walking, 3 for idle.

Rows 4 and 5 were added in an update; rows 1-3 are where they always were, so existing projects keep working.

Transparent PNG. Soft contact shadow included in every frame. See LICENSE.txt for what you can and can't do.

Use it in Godot 4

Set Project Settings → Rendering → Textures → Default Texture Filter to Nearest for crisp pixels. Each sheet is a grid of 4 × 5 frames (see the layout above), so a Sprite2D can step through it:

$Sprite2D.texture = load("res://walking-crew/sheet.png")
$Sprite2D.hframes = 4
$Sprite2D.vframes = 5
$Sprite2D.frame = 0  # row r, column c: r * 4 + c
