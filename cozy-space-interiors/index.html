What's inside

Floors, a rounded steel room frame, front walls and an animated sliding door to build the inside of a space station. Made to match the Cozy Space Station props and the Walking Crew characters.

TILESET  tileset/1x|2x|4x/cozy-space-interiors-tileset.png  (16 px grid, 10 x 7 tiles at 1x)
  row 1   floors: steel, steel plain, steel bolts, steel vent, grate,
          carpet blue, carpet beige, lab
  row 2   floors: hazard stripes, light panel, hatch, empty space;
          then the 4 inner frame corners (nw, ne, sw, se) for L-shaped rooms
  rows 3-5  room frame, 9-slice: nw, n, ne / w, center, e / sw, s, se
  rows 6-7  front walls, 16 x 32 (two tiles tall): wall, window, window with
          planet, screen, vent, pipes, light, sign, door closed, door open

The frame tiles are transparent inside and outside: put them on a layer above the floor. Front walls go in the first row inside the top frame.

Use it in Godot 4

Set Project Settings → Rendering → Textures → Default Texture Filter to Nearest for crisp pixels. Animations are horizontal strips (the number before f.png is the frame count); this turns one into an AnimatedSprite2D:

var sheet: Texture2D = load("res://cozy-space-interiors/tiles/1x/door-4f.png")
var frames := SpriteFrames.new()
var w := sheet.get_width() / 4
for i in 4:
	var frame := AtlasTexture.new()
	frame.atlas = sheet
	frame.region = Rect2(i * w, 0, w, sheet.get_height())
	frames.add_frame("default", frame)
$AnimatedSprite2D.sprite_frames = frames
$AnimatedSprite2D.play("default")
