What's inside

32 PNG files (1x, 2x and 4x, nearest-neighbor, transparent background), in the same palette, roofs and warm outline as the Cozy Farm farmhouse and barn.

buildings/  windmill (48 x 64, blades turning: -frame1..4 and a -strip; loop at ~6 fps),
            silo (32 x 64), greenhouse (64 x 48), stable (64 x 48),
            tool-shed (32 x 32), small-barn (48 x 48)
            Each building sits on the bottom of its canvas, sized in whole 16 px tiles.
examples/   a farmyard with every building (grass, path, trees, props and people
            are from Cozy Farm)

Use it in Godot 4

Set Project Settings → Rendering → Textures → Default Texture Filter to Nearest for crisp pixels. Drop the PNGs into your project and use them as textures; for tiles, add the sheet to a TileSet with the tile size from the README.

$Sprite2D.texture = load("res://cozy-farm-buildings/buildings/1x/greenhouse.png")
