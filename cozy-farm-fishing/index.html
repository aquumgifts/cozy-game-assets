What's inside

104 PNG files (1x, 2x and 4x, nearest-neighbor, transparent background), in the same palette, grid and 1 px warm outline as Cozy Farm.

fish/     carp, trout, salmon, catfish, bass, perch, pike, eel, goldfish, sunfish, minnow, koi
catch/    old-boot, tin-can, treasure-chest
gear/     fishing-rod, worm-bait, fish-bucket, fishing-net, crab-trap
pond/     rowboat, lily-pad, lily-pad-flower, reeds, cattails, stepping-stone
dock/     dock-planks, dock-side-w, dock-side-e, dock-end, dock-end-w, dock-end-e
fish, catch and gear are 16 x 16 inventory icons. The dock is 6 opaque 16 x 16
tiles (planks running north-south, west and east edges, and the end with posts
going into the water) that sit on top of any water tile.
sheets/   fish, catch and gear icons on one 16 px grid
tileset/  the 6 dock tiles in a row
examples/ a fishing pond built from this pack (water, grass, path, trees and
          people are from Cozy Farm)

Use it in Godot 4

Set Project Settings → Rendering → Textures → Default Texture Filter to Nearest for crisp pixels. Drop the PNGs into your project and use them as textures; for tiles, add the sheet to a TileSet with the tile size from the README.

$Sprite2D.texture = load("res://cozy-farm-fishing/catch/1x/old-boot.png")
