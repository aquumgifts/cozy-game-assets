What's inside

8 planets, each with a 24-frame rotation sheet, 8 asteroids, 3 parallax star layers and 3 nebula backgrounds. Every background tile repeats seamlessly.

Folders:
  planets/1x, 2x, 4x      planet-<type>.png               one frame
                          planet-<type>-spin-24f.png      24 frames in a row, loops
  asteroids/1x, 2x, 4x    asteroid-1..8.png               16 px and 24 px
  backgrounds/1x, 2x      stars-far / stars-mid / stars-near-tile.png   128 px
                          nebula-violet / teal / rose-tile.png          256 px

Planet types: terran, desert, ice, lava, toxic, moon, gas, gasblue (ringed). Spin sheets: 48 x 48 px frames at 1x (the ringed planet is 82 x 48), suggested speed 8-12 fps. Scale with nearest-neighbor to keep pixels crisp.

Parallax: put stars-far (opaque) at the back and scroll stars-mid and stars-near (transparent) faster on top. The nebula tiles already include a few stars and work on their own.

Use it in Godot 4

Set Project Settings → Rendering → Textures → Default Texture Filter to Nearest for crisp pixels. Animations are horizontal strips (the number before f.png is the frame count); this turns one into an AnimatedSprite2D:

var sheet: Texture2D = load("res://cozy-space-backdrops/planets/1x/planet-desert-spin-24f.png")
var frames := SpriteFrames.new()
var w := sheet.get_width() / 24
for i in 24:
	var frame := AtlasTexture.new()
	frame.atlas = sheet
	frame.region = Rect2(i * w, 0, w, sheet.get_height())
	frames.add_frame("default", frame)
$AnimatedSprite2D.sprite_frames = frames
$AnimatedSprite2D.play("default")
