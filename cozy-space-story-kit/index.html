Cozy Space Story Kit — HTML5 Visual Novel Template

Write a dialog story in one JS file: talking portraits, choices, flags, music. Art, font and sound included. MIT code.

About it

A ready-to-edit story game in plain HTML and JavaScript (no engine, no build step). Write your dialog in story.js, upload the folder to itch.io, done.

WHAT'S INSIDE

  index.html   the engine: dialog box with typing effect and talking portraits,
               choices, flags, backgrounds, title and end screens, music and
               sounds, keyboard / mouse / touch, sharp pixel scaling
  story.js     the sample story (a short shift on a space station) and the
               settings: title screen, characters, backgrounds, end screen
  assets/      art, font, music and sounds from the free Cozy Space set:
               9 characters x 5 moods + talking (sheets/), dialog boxes (ui/),
               space backgrounds, station rooms, 39 props, Cozy Space Pixel
               Font, 3 music loops and 18 sound effects

WRITE YOUR STORY

  Open story.js in any text editor. Each line of dialog is a node:
    hello: { bg: "lab", who: "rosa", mood: "happy", text: "Hi!", next: "ask" },
    ask:   { bg: "lab", text: "What do you say?", choices: [
             { text: "\"Hello, Rosa.\"", next: "nice", do: (s) => { s.friend = true; } },
             { text: "Say nothing.", next: "quiet" },
           ] },
  • The story starts at the node called "start" and ends with next: "end".
  • who / mood choose the portrait (neutral, happy, sad, angry, surprised). A neutral portrait moves its mouth while the text types.
  • choices can be hidden with if: (s) => ..., and can change flags with do.
  • text, mood and next can also be functions of your flags, for endings.
  • Add characters in CHARACTERS and backgrounds in BACKGROUNDS.

TRY IT

  Images work if you just open index.html, but browsers block sound from local
  files. To hear music and sounds, run a local server in this folder, e.g.:
    python3 -m http.server 8000      then open http://localhost:8000

PUBLISH ON ITCH.IO

  Zip the folder contents (index.html at the top level), upload as an HTML
  project, tick "This file will be played in the browser", set the viewport to
  960 x 540 and enable the fullscreen button.
