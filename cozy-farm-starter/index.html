Cozy Farm Starter

A tiny cozy farming game to play in your browser, and a free open source template to make your own

Download free on itch.ioPlay in your browser

About it

Till, plant, water, harvest, ship. A small top-down farming loop in plain JavaScript: one HTML file for the engine and config.js for everything you would want to change. No engine, no build step, no dependencies.

Play it in your browser: https://aquumgifts.itch.io/cozy-farm-starter

CONTROLS

  Arrows / WASD ........ walk
  Space / Z / Enter .... use the tool on the tile in front of you
  1-5 or Tab ........... choose a tool or a seed bag
  M .................... sound on / off
  On phones: on-screen pad, A to use, B for the next tool.

HOW THE FARM WORKS

  Hoe ........... turns grass inside the fence into soil
  Seed bag ...... plants a seed on soil
  Watering can .. a watered crop grows one step overnight
  Any tool ...... harvests a ripe crop
  Barrel ........ buys seeds
  Crate ......... ships your harvest and ends the day (you get paid overnight)
  The game saves by itself in the browser.

FILES

  index.html        the engine (about 500 lines, commented)
  config.js         map, crops, prices and texts: start here
  assets/           art, sounds and font (see the licenses below)
  LICENSE-code.txt  MIT license for index.html and config.js
MAKE IT YOURS (config.js)
  - Draw a new map: one character per 16 x 16 tile; the legend is in the file.
    Fences and paths connect by themselves, soil autotiles as you till.
  - Change prices, growth speed and starting coins.
  - Add crops: each crop needs a 4-frame strip (seeds, sprout, growing, ready)
    and an inventory icon. The full Cozy Farm has 7 more crops (potato, corn,
    pumpkin, strawberry, cabbage, turnip, sunflower) drawn in exactly this
    format: copy the PNG files into assets/crops and assets/items and add one
    line per crop.
  - The full Cozy Farm also has animated water, the farmhouse, barn and coop,
    8 villagers, cows and a brown hen:
    https://aquumgifts.itch.io/cozy-farm

RUN IT LOCALLY

  Browsers block images loaded from file://, so start a small web server in
  this folder, for example:
      python3 -m http.server 8000
  and open http://localhost:8000

PUBLISH IT ON ITCH.IO

  Zip the contents of this folder (index.html at the root of the ZIP), upload
  it as an HTML project, tick "This file will be played in the browser" and
  set the viewport to 960 x 540 with the fullscreen button on.

MADE FOR JAMS
