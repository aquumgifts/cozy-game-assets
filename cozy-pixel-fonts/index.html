Use it in Godot 4

In the font's Import settings set Antialiasing to None and use the size the README gives (or a multiple of it) so it stays crisp.

var font: FontFile = load("res://cozy-pixel-fonts/font.ttf")
$Label.add_theme_font_override("font", font)
$Label.add_theme_font_size_override("font_size", 16)
